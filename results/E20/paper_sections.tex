\section{Experimental Setup}
This project is a research prototype using archived local result artifacts, controlled synthetic evidence, and metadata for locally acquired public-source snapshots. E20 performs no network acquisition and does not redistribute source data. The local acquisition manifest lists 8 acquired source artifacts; per-source SHA-256 receipts and license/terms review status are recorded in the E20 frozen release manifest. The source-separated train, calibration, and test partitions required for field evaluation were not available as a frozen eligible release. Consequently, the frozen splits are reported as unavailable rather than reconstructed from current feed absence. The E19 controlled graph scales actually completed were: none.

The E20 prospective confirmatory plan was written after E01--E19 outputs already existed; it applies only to the new controlled seed replays and is not represented as preregistration of the archived experiments. The plan freezes replay seeds, the E13 action budget, E18 graph contrast, paired synthetic-case cluster bootstrap, sign-flip tests, and Holm correction. Synthetic case clusters are not campaigns and do not support field-level uncertainty.

\section{Threats to Validity}
The main limitations are absence of authenticated historical availability times, no approved external campaign-disjoint test release, missing original URLTrust implementation/source pin, incomplete license/redistribution adjudication for several snapshots, single-seed archived runs for many stochastic experiments, and lack of campaign/source-cluster identifiers. Controlled data may not represent real source dependencies, adaptive attackers, network failures, or operational collection costs. A passing software soundness test does not establish phishing-detection effectiveness.

\section{Ethical Restrictions and Code/Data Availability}
No active crawling, form submission, page execution, or live-target interaction is performed by E20. Locally acquired feeds and datasets remain subject to their upstream terms and are not copied into the E20 report. The report publishes hashes and metadata only. Independent reproduction requires the same permitted local snapshot bytes and receipts; restricted artifacts require the applicable source authorization, agreement, and release-specific hashes. The offline command is \texttt{python -m cerurl.cli run-e20}; it never downloads mutable feeds.
